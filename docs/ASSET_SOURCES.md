# منابع و مجوز دارایی‌های بصری

| دارایی | منبع | مجوز/وضعیت | محل استفاده | وضعیت انتشار |
|---|---|---|---|---|
| Noto Sans Arabic Variable | بسته `@fontsource-variable/noto-sans-arabic@5.2.8`، پروژه Google Fonts | SIL Open Font License 1.1 | تایپوگرافی کل رابط | مجاز؛ فایل‌ها داخل باندل وب |
| Vazirmatn Variable | بسته `@fontsource-variable/vazirmatn@5.2.8`، پروژه Fontsource/Vazirmatn | SIL Open Font License 1.1 | متن، کنترل‌ها و fallback تیترهای فارسی | مجاز؛ فایل‌ها داخل باندل وب |
| IranYekan / IranYekanX | فایل دارای مجوز دریافت نشده | فونت تجاری؛ حق توزیع تأیید نشده | جایگاه نخست تیترها پس از دریافت فایل مجاز | مسدود تا تحویل فایل و مجوز |
| آیکون‌های رابط | SVG تألیفی در `apps/web/src/components/Icon.tsx` | کد اختصاصی همین پروژه | ناوبری، اعتماد، فرم و پنل | مجاز |
| نقشه تبدیل مسئله | SVG/CSS تألیفی در `TransformationDiagram.tsx` | کد اختصاصی همین پروژه | هیرو و بخش یکپارچگی | مجاز |
| `canon.png` | خروجی تولیدی برای تصمیم طراحی | فقط مرجع طراحی داخلی؛ نباید به کاربر نهایی سرو شود | `.impeccable/mocks/decision/` | غیرقابل انتشار به‌عنوان دارایی سایت |
| تصاویر تیم، مشتری و پروژه واقعی | هنوز دریافت نشده | مجوز انتشار وجود ندارد | placeholderهای آشکار | مسدود تا رضایت مکتوب |
| لوگو و نشان تجاری نهایی | هنوز دریافت نشده | هویت بصری تأیید نشده | نشان هندسی فعلی موقت است | مسدود برای production نهایی |

هیچ لوگوی مشتری، تصویر اشخاص، نمونه‌کار واقعی یا ادعای قابل انتساب بدون مدرک و رضایت انتشار در build عمومی قرار نگرفته است. هر افزوده جدید باید نام صاحب اثر، URL یا مسیر منبع، نوع مجوز، تاریخ دریافت، محدودیت استفاده و متن جایگزین را در همین جدول ثبت کند.

## تصمیم مالک درباره تصاویر

مالک در ۱۴۰۵/۰۶/۱۳ همه تصاویر استوک پیشنهادی را رد کرد. هیچ‌کدام دانلود، باندل یا در رابط استفاده نشده‌اند. جهت فعلی عمداً بدون عکس استوک ادامه پیدا می‌کند و دارایی‌های بصری آن تألیفی و کدنویسی‌شده هستند.
