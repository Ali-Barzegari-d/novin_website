# Source documents

- `PRD.docx`: original product requirements source provided by the owner.
- `PRD.md`: searchable Markdown extraction of the complete DOCX. Use the DOCX if extraction ambiguity is suspected.
- `PRODUCT_DISCOVERY.md`: original request, all clarification questions, and the owner's numbered answers.
- `TRACEABILITY.csv`: implementation ledger generated from 137 functional, business-rule, non-functional, and acceptance IDs in the PRD.
- `SKILL_PROVENANCE.md`: record for external agent skills used during implementation.
- `SOURCE_INTEGRITY.md`: handoff checksums for the source and traceability files.

Do not edit the original DOCX. Product changes belong in a new versioned decision/PRD update with owner approval.
